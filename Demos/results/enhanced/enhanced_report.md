# 进阶增强模块 · 真实样本实验（FBID）

- 样本：3883 个真实标注框裁剪（train），64×64
- 特征：32×32 灰度下采样 + 8×8 RGB 彩色块均值（共 1216 维）；freq 为 CWT/VMD 融合后同维特征
- 类别计数：{'normal': 1331, 'flashover': 1729, 'broken': 823}

| 模块 | 指标 | 数值 |
| --- | --- | ---: |
| freq | 最近类中心 acc（空间） | 40.78% |
| freq | 最近类中心 acc（+CWT/VMD） | 38.98% |
| freq | Δ | -1.80% |
| graph | MSA-GCN acc（全部节点） | 45.71% |
| graph | MSA-GCN acc（无标签节点） | 46.35% |
| graph | 训练损失首/末 | 1.141 / 0.872 |
| cdmth | 5-shot acc | 42.56% ± 5.28% |
| cdmth | 10-shot acc | 45.91% ± 2.68% |

- freq 结论：频域融合在本组裁剪上是**负增益**：VMD/CWT 提取的纹理对「污秽 vs 闪络」的区分度不如原始的灰度+颜色块统计；这个信号更适合放进光照/退化归一化分支，而不是直接当判别特征用。
- graph 结论：半监督图网络在只有 20% 标签时仍能到 46.35%，是目前三个模块里判别性最好的一个（3 类随机基线 33%）；但它依赖同类样本成簇，跨工况泛化还需实测。
- cdmth 结论：原型头在 5/10-shot 下给出可测的少样本基线，数字直接来自真实缺陷裁剪，可直接作为「少样本补充方案」的对照。
- cdcgan：生成实验不在本脚本里，见同目录 `cdcgan_*/`（`scripts/train_cdcgan.py` 产出样本图、损失曲线与中心距筛选指标）。

> 口径：这些是**模块级可执行实验**，用真实标注框的块统计特征与 numpy 实现，
> 目的是验证模块在真实数据上跑得通、有可测的判别性，不代表接进 YOLO 主干后的最终增益。
