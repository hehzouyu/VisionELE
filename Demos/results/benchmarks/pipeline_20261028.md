## 4. 口径说明（重要）

1. **检测不是真实模型**：`SimulatedDetector` 按相机内参/视场/距离裁剪，从地面真值点反推像素框，置信度只加了 ±0.02 抖动；因此 mAP、漏检率、真实延迟都不适用，真实精度需训练 CA-YOLO 后用 `scripts/benchmark_vision.py` 另测。
2. **单目地面投影**：世界坐标由 `coords.py` 假设缺陷落点在地面 z=0 反算，是仿真阶段近似，实机需标定或换测距/双目。
3. **延迟口径**：单步墙钟时间，含 Python 开销与调度器入队；p95 为线性插值分位数；max 长尾来自首次调用/内存分配，不代表稳态。
4. **碰撞口径**：车体参考点落入原始占据栅格即计一次；本场景全程为 0，但膨胀图上仍留 0.3 m 安全半径。
