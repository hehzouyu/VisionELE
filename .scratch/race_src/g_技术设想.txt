[Heading 3] 1.1 研究目标
针对变电站巡检中绝缘子缺陷“表面微小难定位、内部劣化不可见、长条状结构感知弱、噪声干扰强、罕见缺陷样本极少、标注成本极高”六大瓶颈，构建视觉-电气双域协同的智能巡检系统。核心突破在于将MSA-GCN的半监督多尺度图学习范式从轴承振动诊断迁移至工业视觉与电气信号联合检测，实现每类5–10张标注样本下的高可靠缺陷识别。

[Heading 2] 3. 视觉模态详细实现方案
[Heading 3] 3.1 WDCNN宽核结构编码器
网络结构：基于YOLOv8-Nano Backbone改造，仅替换首层卷积。
<<TABLE>>
层 | 配置 | 输出尺寸 | 作用
Stem | Conv2d(3→64, kernel=7, stride=2, padding=3) | H/2 × W/2 × 64 | 宽核捕捉长条状全局结构
或 | Conv2d(3→64, kernel=3, dilation=3, stride=2) | H/2 × W/2 × 64 | 等效感受野7×7，参数量↓
Stage1 | C2f(64→128, n=3) | H/4 × W/4 × 128 | 标准特征提取
Stage2 | C2f(128→256, n=6) | H/8 × W/8 × 256 | CA注意力插入位置
Stage3 | C2f(256→512, n=6) | H/16 × W/16 × 512 | 深层语义
Stage4 | C2f(512→1024, n=3) | H/32 × W/32 × 1024 | 全局语义
<<END TABLE>>
宽核原理：首层7×7卷积核的静态感受野为 ，大于标准  堆叠3层后的等效感受野（仅  但需3层非线性变换）。宽核在首层即建立长程空间关联，避免小核在深层丢失细长裂纹的低频结构信息。

[Heading 2] 7. 训练策略与边缘部署优化
[Heading 3] 7.1 训练流程
阶段一：宽核基线与单模态预训练（Epoch 1–100） - 视觉域：WDCNN+YOLO在COCO预训练权重上微调，冻结Stage3/4，仅训练Stem+Stage1+检测头； - 电气域：四分支独立训练，MSA-GCN图分支采用半监督损失。
阶段二：图学习联合训练（Epoch 101–250） - 释放所有层，联合训练MSA-GCN视觉图+RGAB+EdgePool； - 引入cDCGAN生成数据，与真实数据按1:1混合； - 学习率衰减：初始 ，Epoch 150降至 ，Epoch 200降至 。
阶段三：双模态对齐与域适应（Epoch 251–350） - 加入MMD损失与域对抗损失； - 冻结cDCGAN生成器，仅训练判别器与筛选器； - 激活CDMTH元迁移头，进行 -shot 原型学习。
优化器：AdamW，权重衰减 ，。

class HybridGraphBuilder(nn.Module):
    def __init__(self, in_dim=512, proj_dim=128, k=5, sigma=None):
        self.mlp = nn.Sequential(nn.Linear(in_dim, proj_dim), nn.ReLU())
        self.k = k
        self.sigma = sigma  # 默认=in_dim/2
        
    def forward(self, node_feats):
        # GGL动态构图
        x_proj = self.mlp(node_feats)  # [n, proj_dim]
        A_dense = F.normalize(x_proj @ x_proj.t(), dim=1)  # 余弦相似度
        A_sparse, edge_idx = top_k_sparse(A_dense, k=self.k)  # COO格式
        
        # FFT频域精修
        fft_feats = torch.fft.rfft(node_feats, dim=-1).abs()[:, :node_feats.size(-1)//2]
        d_freq = torch.cdist(fft_feats, fft_feats, p=2)
        weights = torch.exp(-d_freq**2 / (2 * self.sigma))
        A_weighted = A_sparse * weights[edge_idx[0], edge_idx[1]]
        return edge_idx, A_weighted

# 模块2: RGAB (残差图注意力块)
# ============================================
class RGAB(nn.Module):
    def __init__(self, in_dim, hidden_dim, num_scales=3):
        self.ms_convs = nn.ModuleList([
            ChebConv(in_dim, hidden_dim, K=j) for j in range(1, num_scales+1)
        ])
        self.aff = AdaptiveFeatureFusion(hidden_dim, num_scales)
        self.gat = GATConv(hidden_dim, hidden_dim, heads=1)
        self.bn = nn.BatchNorm1d(hidden_dim)
        
    def forward(self, x, edge_index, edge_weight):
        multi_scale_feats = [conv(x, edge_index, edge_weight) 
                            for conv in self.ms_convs]
        h_fused = self.aff(multi_scale_feats)  # [n, hidden]
        h_att = self.gat(h_fused, edge_index)
        return F.relu(self.bn(h_att)) + x  # 残差

# 模块3: 可逆EdgePool
# ============================================
class ReversibleEdgePool(nn.Module):
    def forward(self, x, edge_index, edge_weight, batch):
        # 计算边得分并合并
        row, col = edge_index
        edge_score = self.compute_edge_score(x[row], x[col])
        x_new, edge_index_new, batch_new, merge_log = edge_contract(
            x, edge_index, edge_score, batch, reduce='add'
        )
        return x_new, edge_index_new, batch_new, merge_log
    
    def unpool(self, x_pooled, merge_log):
        # 根据merge_log广播父节点特征至子节点
        x_unpooled = x_pooled[merge_log.parent_idx] * merge_log.scores[:, None]
        return x_unpooled

# 模块4: 跨模态MMD损失
# ============================================
class MMDLoss(nn.Module):
    def __init__(self, kernel_mul=2.0, kernel_num=5):
        self.kernel_num = kernel_num
        self.kernel_mul = kernel_mul
        
    def forward(self, source, target):
        # source: [n, d], target: [m, d]
        n = source.size(0)
        m = target.size(0)
        total = torch.cat([source, target], dim=0)  # [n+m, d]
        L2_distances = torch.cdist(total, total, p=2).pow(2)
        
        # 多带宽RBF核
        bandwidth = L2_distances.data.sum() / (n+m)**2
        bandwidth /= self.kernel_mul ** (self.kernel_num // 2)
        kernel_val = sum([
            torch.exp(-L2_distances / (bandwidth * (self.kernel_mul**i)))
            for i in range(self.kernel_num)
        ])
        
        XX = kernel_val[:n, :n].sum() / (n*n)
        YY = kernel_val[n:, n:].sum() / (m*m)
        XY = kernel_val[:n, n:].sum() / (n*m)
        return XX + YY - 2*XY
