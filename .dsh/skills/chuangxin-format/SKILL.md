# 创新创业课程报告格式规范（本项目专用）

依据目录 `创新创业课/课程要求模板/` 下的四份文件。**只管"长什么样"，不管"写什么"**：章节内容与论证走 `chuangxin-report`，引用哪篇文献走 `chuangxin-literature`。三份职责互不越界。

## 格式源与优先级

| 编号 | 文件 | 用在哪 |
|---|---|---|
| A | `电气工程综合创新创业 课程报告模板（理论课）.docx` | 理论课报告（标题黑体四号/正文宋体小四/1.2 倍行距/图下表上黑体五号） |
| B | `电气工程综合创新创业 课程报告模板（实践课）.docx` | 实践课报告（格式同 A） |
| C | `中文论文参考格式-仅供参考.doc` | 需要投稿/竞赛论文时：学报体例（小二幼圆题名、5 号宋体正文、三线表、GB/T 7714 参考文献） |
| D | `英文论文参考格式-仅供参考.doc` | 需要英文论文/英文摘要时：会议体例（Times New Roman、APA 7 参考文献） |

**优先级**：课程报告用 A/B，A 与 B 的格式条款逐字相同；C/D 只在"论文投稿、竞赛论文、英文摘要"时用。课程报告**不要**套用 C 的字号体系（5 号正文太密、幼圆题名不符课程要求）。

## 一、课程报告硬格式（A/B 共用，错一条就扣分）

| 项 | 规定 |
|---|---|
| 标题 | 黑体四号加粗；序号层级 `1 → 1.1 → 1.1.1 →（1）→ ①` |
| 正文 | 宋体小四 |
| 行距 | 1.2 倍行距 |
| 图标题 | 图**下方**居中，黑体五号；编号"图 1-1" |
| 表标题 | 表**上方**居中，黑体五号；编号"表 1-1" |
| 封面 | 「《电气工程综合创新创业》课程报告」或「《电气工程创新创业实践》课程报告」+ 题目行 + 6 人（姓名/班级/学号）+ 年月（模板写"202 年9月"） |
| 结构页顺序（理论课） | 封面 → 课程报告要求（照抄原文，不改写）→ 团队分工情况说明 → 一、课程报告 → 二、PPT 汇报内容 → 三、课程学习总结（每人一份）→ 四、成绩评价（每人一张表） |
| 结构页顺序（实践课） | 封面 → 课程报告要求（7 条）→ 团队分工情况说明 → 一、课程报告 → 二、成绩评价（每人一张表）；**无**学习总结、无 PPT 要求页 |
| 成绩评价表 | 每人一张，三行：学习过程 20% / 课程设计成果展示 40% / 课程设计汇报答辩 40%，合计 100% |

## 二、中文论文参考格式（C，学报体例）

**只在投学报/竞赛论文时启用，逐项摘录自模板：**

| 项 | 规定 |
|---|---|
| 中文题名 | 小二号幼圆加粗，居中 |
| 作者 | 小四号黑体；不同单位用数字上标（1、2），同单位不同院系用字母（1a、1b） |
| 单位 | 5 号宋体，括号内；写至学院或系；地址是省会城市则省略省名 |
| 摘要 | 「【背景与目的】【研究方法】【创新点】【结论】」分段式；250 字左右；不引文献、不评价、不重复题目 |
| 关键词 | 5 个左右，分号隔开 |
| 作者简介 | 姓名（出生年—），性别，职称/学位，研究方向；通信作者给邮箱 |
| 引言 | 交代背景、意义，归纳前人工作找问题；一般不用图表公式；推荐 1-2 段；英文缩写首次出现格式"中文全称(英文全称，缩写)" |
| 正文 | 5 号字，宋体，英文用 Times New Roman，**单倍行距** |
| 层次标题 | 序号一律左顶格："1"、"1.1"、"1.1.1"；标题不超过 15 个汉字；非标题序号用 a)、b)、c) |
| 量符号 | 变量斜体；矢量/矩阵粗斜体；函数符号与数字正体；首次出现给出含义 |
| 单位 | GB 3100—1993 国际 SI 制；数值与单位间空格；组合量用"量/(单位)"格式 |
| 公式 | 重要/复杂/需编号的另行居中排；编号在圆括号内靠右；公式后"式中：A 为……"说明；用 Mathtype 编辑 |
| 插图 | 图随文后，先正文引用再出现；图题在图**下方**居中，中文"图1 …"英文"Fig.1 …"双题；照片需清晰，彩图转黑白 |
| 表格 | 必须"三线表"（无竖线）；表题在表**上方**居中，中英双题；参数写明名称与单位；表注在表底线下左侧；未测标"-"、结果 0 标"0" |
| 结论 | 不可缺少；概括创新点、说明结论与规律、指出不足与后续建议；不与摘要/引言雷同 |
| 参考文献 | 小 5 号字，宋体，数字与英文用 Times New Roman，单倍行距；正文按自然数顺序上标标引 `[1]`；GB/T 7714 著录；中文文献后附英文对照 |

## 三、英文论文参考格式（D，会议体例）

**只在写英文论文/英文摘要时启用：**

| 项 | 规定 |
|---|---|
| Title | Times New Roman **20 pt**，加粗，居中 |
| Authors | TNR 12 pt，居中；通讯作者加 * |
| Affiliation | TNR 10 pt，居中，含国家 |
| Abstract | 200–250 词；TNR 12 pt；**block 对齐**；行距 1.0；写目的/方法/数据/主要结果，不写评价 |
| Keywords | 最多 5 个 |
| Headings | 一级 TNR 14 pt 加粗；二/三级 TNR 12 pt 加粗 |
| Body | TNR 12 pt；block 对齐；行距 1.0；按 IMRaD（Introduction/Methods/Results/Discussion）+ Conclusion 组织 |
| Figures | 图题在图下：`Figure 1: description`，TNR 10 pt，居中，斜体；源注 TNR 10 pt 斜体 |
| Tables | 表题在表上：`Table 1: description`，TNR 10 pt 斜体；表内文字 TNR 10 pt；图/表编号为 Tab.1、Fig. 1 并在正文引用 |
| Equations | 居中排，圆括号编号 (1)(2)；用公式编辑器，禁止截图/jpg |
| References | 正文引用格式 (Surname, year)、(Surname & Surname, 2014)、(Surname et al., 2012)；文末 APA 7th 风格 |
| Footnote | TNR 10 pt |

## 四、三套模板怎么混用（避免格式打架）

1. **课程报告 = A 或 B 的字号体系**，正文宋体小四、1.2 倍行距、图下表上黑体五号。不要因为引用了 C 的"参考文献 5 号字"就把正文也改成 5 号。
2. **参考文献条目格式**：课程报告用 GB/T 7714（中文格式），不要用 APA；只有英文论文（D）才用 APA 7。
3. **英文摘要/英文关键词**：如果报告里出现英文摘要，按 D 的 Abstract 规则（TNR 12 pt、1.0 行距、250 词内），但正文其余部分仍按 A/B。
4. **图表编号**：课程报告用"图 1-1 / 表 1-1"（章节-序号）；论文（C/D）用"图1 / 图 2(a)"与 `Tab.1 / Fig. 1`。两套别混。
5. **层次编号**：课程报告 `1 → 1.1 → 1.1.1 →（1）→ ①`；论文 C 用 `1 → 1.1 → 1.1.1` 且顶格。课程报告允许（1）与①，论文不允许跳级。

## 五、交稿前格式自查（逐条打勾）

- [ ] 封面：课程名正确、6 人信息齐全、年月对
- [ ] "课程报告要求"页是模板原文（理论课 3 项 / 实践课 7 条），没改写、没漏条
- [ ] 标题黑体四号加粗；正文宋体小四；行距 1.2 倍（全选检查一次）
- [ ] 层级序号 1/1.1/1.1.1/（1）/① 无跳级、无混乱
- [ ] 每张图：正文先引用（"如图 1-1 所示"）、图题在图下居中黑体五号
- [ ] 每张表：表题在表上居中黑体五号、表格是三线表（无多余竖线）
- [ ] 参考文献：GB/T 7714、正文上标编号与文末一一对应、中文条目后附英文对照
- [ ] 英文摘要（如有）：TNR 12 pt、1.0 行距、不超 250 词、关键词 ≤5
- [ ] 理论课有"三、课程学习总结"（每人一份不重样）与"二、PPT 汇报内容"；实践课没有这两节
- [ ] 成绩评价表按人数复制、姓名已替换、合计 100%
- [ ] 全文图表编号连续、正文引用与图表一一对应

## 常见错误

- 把课程报告套成学报格式：正文 5 号宋体单倍行距、题名幼圆——课程模板要求小四 + 1.2 倍，套错直接扣格式分
- 表格画成网格线表——课程模板虽未强制三线表，但 C 明确要求"三线表（无竖线）"；课程报告也建议三线表更稳
- 图题写在图上方 / 表题写在表下方——方向记反（图下表上）
- 参考文献用 APA——课程报告要 GB/T 7714
- 结构页顺序缺页：理论课漏了"课程报告要求"或"学习总结"页，实践课多塞了 PPT 页
- 英文摘要直接翻译中文摘要塞进去，没压到 250 词、行距没改 1.0
- 字号混用：标题用了黑体三号、正文用了仿宋——以模板四条规定为准，不临场发挥
